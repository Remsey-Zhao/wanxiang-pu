# 万相谱 · 本命道途

一份关于**做事风格**的幻想角色图鉴。不是性格好坏测试，也不涉及命理或心理诊断。

- 20 个真实工作情境
- 12 条风格维度
- 16 种幻想职阶 × 3 种元素相 = 48 种角色
- 生成一张可保存、可分享的本命海报

角色横跨西境与东洲：战士、法师、女巫、精灵、盗贼、圣骑士、德鲁伊、吟游诗人，以及剑修、拳师、符师、丹修、御兽师、傀师、琴修、画师。
